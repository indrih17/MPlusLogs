# Embedded media libraries

These unmodified library sources were copied from the locally installed
BuffReminders distribution on 2026-10-25. Source headers retain authorship and
upstream revision identifiers. MPlusLogs loads them through LibStub, so a newer
compatible library already loaded by another addon is retained.

- LibStub 2, revision 103: public domain, declaration in `LibStub/LibStub.lua`.
- CallbackHandler-1.0: Ace3 license in `CallbackHandler-1.0/LICENSE.txt`.
- LibSharedMedia-3.0 12.0.0 v4 (`12000004`), revision 181: LGPL 2.1 in
  `LibSharedMedia-3.0/LICENSE.txt`.

Upstream projects:

- https://www.wowace.com/projects/libstub
- https://www.wowace.com/projects/callbackhandler
- https://www.wowace.com/projects/libsharedmedia-3-0

No third-party font files are bundled. The library exposes Blizzard resources
and media registered by other addons; optional media packs supply extra fonts.
