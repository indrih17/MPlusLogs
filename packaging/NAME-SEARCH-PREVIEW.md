# Поиск участников группы через API

Локальная пробная сборка. Публичные релизы и канал обновлений не изменены.

## Как попробовать

1. Полностью выйти из Companion через трей и установить обычную сборку
   `release-output/MPlusLogs-Companion-API-Search-Preview-3-Setup.exe`.
   Внутренняя версия пока 1.0.20; это установщик, не portable.
2. Запустить Companion, проверить вход в Warcraft Logs, в игре сделать `/reload`.
3. ПКМ по найденной группе → «M+ логи (MPlusLogs)».
4. В стандартном окне обмена скопировать запрос через Ctrl+C, дождаться
   ответа Companion и вставить через Ctrl+V.
5. Откроется таблица логов с вкладками участников. При нескольких подходящих
   персонажах выбрать сервер в аддоне и повторить обмен в стандартном окне.

Если состав не изменился и профили свежие, повторное открытие той же группы
сразу показывает сохранённые логи, без запроса. После загрузки открывается
новая сводка «Все специализации», а не ранее выбранная старая специализация.
Старые специализации не удаляются. Дата кэшированного ответа сохраняется.

## Как работает поиск

- Используется только официальный GraphQL API WCL. Нет обращений к поиску
  сайта, открытия WebView, загрузки cookies или решения проверок «не бот».
  WebView2/.NET-компоненты исключены из собранного приложения.
- Для неизвестных серверов проверяется весь каталог региона, пакетами до
  80 пар «имя + сервер», без загрузки рейтингов на этапе поиска.
  Снимок содержит 938 серверов пяти регионов; аудит описан в
  `REALM-AUDIT-2026-10-18.md`.
- Все серверы проверяются до вывода о единственном совпадении. Неполный скан,
  ошибка API и отмена не становятся отсутствием персонажа или единственным
  результатом. Неполный результат не кэшируется.
- Класс проверяется по справочнику WCL, сервер — по ID. Требуемый текущий
  максимальный уровень передаёт игра: сейчас 90 для M+. Исторические уровни
  70, 100, 120 не подходят. Записи WCL с нулевыми классом и уровнем игнорируются
  как неопределённые старые сведения, не прерывая поиск других участников.
- Загрузка логов использует обычный Client с OAuth, ограничениями частоты
  и бюджета. Метаданные не используют часовой запрет обновления профиля.
- Полный поиск кэшируется на час, пустой — на пять минут. Ответы профилей
  сохраняются на час. Кэш работает после перезапуска и разделяется по аккаунтам.
- Без сервера из игры совпадение остаётся предположительным. При нескольких
  результатах пользователь выбирает сервер внутри аддона.
- Выбор сервера строится после проверки доступных M+ измерений текущего
  сезона. Читаемый профиль без измерений DPS/HPS не конкурирует с профилем,
  у которого логи есть. Скрытый профиль, повреждённый ответ или ошибка API
  не считаются пустыми логами и не позволяют выбрать другой профиль автоматически.
- Ошибка профиля не блокирует остальные. Повреждённый пакет, чужой запрос
  и изменившийся состав отклоняются до сохранения.

Диагностика последней группы: `.wcl-cache/name-search-diagnostic.json`.
Только публичные имена, классы, уровни, серверы кандидатов и причины отказа;
без токенов и постороннего содержимого буфера обмена.

## Проверки и ограничения

Живой сквозной прогон API → Companion → настоящий Lua-код загрузил
Gauchosham/Eredar, Zaratrass/Eredar, Filtráki/Twisting Nether и Rhynozeros/Thrall
за 17.77 секунды и 18 запросов. Отдельный скан четырёх имён по 268 серверам EU
использовал 14 запросов и наблюдаемые 15 пунктов из лимита 3600, включая
контрольный запрос лимита. Это измерение, не обещание постоянного времени.

Повторное открытие проверено без нового обмена и новых запросов. Исторические
записи Zaratrass и Gauchosham на Blackhand имеют уровень 70 в API и не проходят
проверку уровня. Проверены перезапуск, разделение аккаунтов, отмена,
неполные ответы, старые кэши и отказы API. Полный набор: 358 тестов,
один пропущен. WoW API в автотестах имитируется; визуальная проба в игре —
отдельный шаг.

На реальных сохранённых ответах Billan/Neptulon и Billan/Stormscale проверен
полный импорт: Neptulon без текущих измерений исключается из вариантов логов,
а Stormscale с восемью подземельями открывается автоматически. Это выбор
доступного профиля логов, не доказательство личности игрока без сервера из игры.

Индекс WCL может отсутствовать или устареть; скрытые логи и сбои API возможны.
Более шести совпадений требуют уточнения сервера. Каталог — снимок от
18 октября 2026 года, новые серверы требуют обновления.

В рабочей папке есть изменения других задач. Публикация требует просмотра
общего diff и отдельного явного подтверждения пользователя.
