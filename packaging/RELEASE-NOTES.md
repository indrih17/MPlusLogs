## MPlusLogs 0.6.0 / Companion 1.0.32

- Add live appearance editing with reusable profiles, independent styles and palettes, SharedMedia fonts, table controls, dungeon labels and import/export.
- Refine all six built-in layouts and dark palettes, use 121212FF table headers and normal key-level digits by default, and resize the window to visible content.
- Smooth editor scrolling, fix scrollbar track direction and dragging, and highlight expandable style and palette libraries with backgrounds and drawn arrows.
- Open appearance directly from the profile header and explain preview, Save and Cancel in general settings and the localized tutorial.
- Preserve Warcraft Logs result colors for stale profiles and improve failed-download feedback and retry handling without discarding cached logs.
