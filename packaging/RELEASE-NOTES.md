First public release, version 0.5.0.

- Mythic+ Warcraft Logs DPS/HPS profiles in player panels and group finder tooltips.
- Request-specific Ctrl+C / Ctrl+V transfer between WoW and the Windows Companion.
- Browser sign-in with PKCE and local DPAPI-protected tokens.
- Windows tray, optional startup with Windows or WoW Retail, system/light/dark themes.
- Addon localization for eleven locales. Companion UI currently uses Russian.

Downloads:
- **MPlusLogs-0.5.0.zip**: addon only; install through CurseForge or extract into AddOns.
- **MPlusLogs-Companion-0.5.0-Setup.exe**: recommended Windows 10/11 x64 installer; no Python installation required.
- **MPlusLogs-Companion-0.5.0-Windows-x64.zip**: portable alternative; extract the complete folder.
- **SHA256SUMS.txt**: download checksums.

The binaries are unsigned. Warcraft Logs sign-in and a working internet connection are required for fresh profiles. Percentiles reflect logged runs, not all player activity or tank survival.
