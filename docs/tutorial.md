# MPlusLogs guide

The guide opens with `/mpl tutorial` or the Open guide button at the bottom of
Settings > MPlusLogs. It never opens automatically on login or first use.
Contextual help is available in the profile header, download dialog header and beside
Load all logs. Clicking help opens the relevant chapter. The download remains
open behind the guide, preserving its request and copy/paste phase; closing the
guide restores input focus when the same request is still active.

The Hide tutorial help outside settings checkbox sits immediately above Open guide
at the bottom of Settings > MPlusLogs. It hides contextual guide buttons and the
initial Companion setup hint; the settings entry and `/mpl tutorial` remain
available. The final chapter offers the same choice for after completion. This
choice is saved only when Done is clicked; closing the guide does not apply it.

`/mpl testintro` previews the first-load Companion hint in the download dialog,
even after setup was acknowledged or a Companion reply was received. It reuses
an existing exchange, or prepares a request for the player if none is active.
The preview does not reset saved setup/history flags and ends when the dialog
is closed or a new request opens. `/mpl tutorial` opens the full guide.

It follows nine tasks: prepare Companion,
load current applicants, exchange the request and reply, read the Logs column,
inspect a profile, check a dungeon and its WCL source, inspect a listing, inspect
your party or a character, and adjust settings.

Each chapter contains a compact location card, instructions, an expected result
and a practical caveat. The guide does not depend on screenshots or image assets.
The contents list and current chapter are preserved independently of imported
profiles, Companion requests and addon settings. The down arrow appears only at
the top of a chapter that requires scrolling.

Russian and English text is in `TutorialSteps.lua`. The other nine translations
are in `Locales/Tutorial/<locale>.lua` and register after that file in the TOC.
All eleven addon locales have their own guide; enGB uses enUS and unknown locales
fall back to English. These are static bundled translations, with no translation
service or network access at runtime.

When editing translations, preserve step IDs/order, action names, command names,
keyboard shortcuts and the two `%d` progress placeholders. Keep quoted control
labels consistent with the addon's locale dictionary. Use short contents labels
and check text wrapping in the target game client. Tutorial locale files are
authored directly and are not generated by `tools/localize_addon.py apply`.

Validate the guide with `python -m unittest discover -s tests -p 'test_tutorial*.py'`.
The archive tests also check that every tutorial translation reaches both the
addon ZIP and the allowlisted public source export. Tests cover structure and
runtime behavior; they do not replace in-game visual or native-speaker review.

## Customize the profile window

Choose **Original layout** in Appearance style to use the previous profile header.
The modern header remains the default. Header layout can also be changed separately.

Click **Appearance** in the profile window header, use `/mpl appearance`, or open
the **Appearance** section at the top of Settings > AddOns > MPlusLogs. General settings
remain available through `/mpl settings`.

Choose a theme, then adjust colors and opacity, fonts, grid lines, visible columns,
number spacing and dungeon labels. Use **Sample preview** to see fictional data
through the real profile renderer without requesting logs. **Current profile**
shows the existing real profile when one is open. Changes appear immediately.

Click **Save** to keep the changes. **Cancel**, the close button and Escape discard
the editor draft, including theme management and personal dungeon labels. Existing
users start with **Classic**; selecting another theme is optional. Use
`/mpl appearance reset` to restore Classic and recenter the profile for the current
character without deleting other saved themes. Additional SharedMedia font packs
are optional; the game interface font is always available.
